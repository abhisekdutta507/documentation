# 🧠 Low-Level Design (LLD)
*LLD is the discipline of detailing how the individual components of a software system are implemented. It bridges the gap between high-level design and concrete code, focusing on class structure, interfaces, and implementation patterns.*

## 🧭 LLD Knowledge Index
*   **Design Patterns**:
    *   [Creational Design Patterns](/LLD/creational-design-patterns/README.md): Patterns focused on object creation mechanisms (e.g., Singleton, Factory).
    *   [Behavioral Design Patterns](/LLD/behavioral-design-patterns/README.md): Patterns that describe communication between objects (e.g., Observer, Strategy).
    *   [Structural Design Patterns](/LLD/structural-design-patterns/README.md): Patterns that deal with class composition and object relationships.
*   **SOLID Principles**:
    *   [SOLID Principles](/LLD/SOLID/README.md): The five design principles that guide the creation of maintainable and scalable object-oriented designs.
