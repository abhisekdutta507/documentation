# 🔒 Constants in Java: Immutable Values and Best Practices
*A guide to declaring and using constants in Java, focusing on why immutability is critical in concurrent programming and interviews.*

```java
public class Main {
    static void main() {
        final float PI = 3.14F;
        System.out.println(PI);
    }
}
```

Output:

```sh
3.14
```
