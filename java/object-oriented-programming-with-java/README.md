# ☕ Object-Oriented Programming in Java

Learn how Java classes and objects work together to make code easier to reuse, change, and test. These guides cover core OOP ideas and common interview topics, with short examples to help you remember each one.

## 🧱 Classes and Objects

- [Classes](./classes/README.md) — Define the data and actions an object can have.
- [Constructors](./constructor/README.md) — Set up an object when it is created.
- [Constructor Overloading](./constructor-overloading/README.md) — Create objects in more than one way.
- [Static Members](./static-members/README.md) — Share fields and methods across a class.
- [Final Classes and Methods](./final-classes-and-methods/README.md) — Prevent a class from being extended or a method from being changed.
- [Object Comparison](./object-comparison/README.md) — Compare object identity and object values.

## 🔄 Reuse and Flexible Behavior

- [Inheritance](./inheritance/README.md) — Build a class from another class.
- [Polymorphism](./polymorphism/README.md) — Use one parent type for objects with different behavior.
- [Method Overloading](./method-overloading/README.md) — Use one method name with different parameter lists.
- [Abstract Classes](./abstract-classes/README.md) — Share common code while leaving some behavior to subclasses.
- [Interfaces](./interface/README.md) — Describe behaviors that different classes can provide.
- [Abstract Class vs Interface](./difference-between-abstract-class-and-interface/README.md) — Compare their features, examples, and best use cases.

## 🛠️ Design Better Classes

- [Abstraction and Coupling](./abstraction-and-coupling/README.md) — Show the needed actions and hide internal details.
- [Encapsulation](./encapsulation/README.md) — Protect an object's data behind clear methods.
- [Dependency Injection](./dependency-injection/README.md) — Give a class the objects it needs instead of creating them inside.
- [Interface Segregation](./interface-segregation/README.md) — Prefer small interfaces with focused jobs.
- [Mortgage Calculator](./mortgage-calculator/README.md) — See OOP ideas used together in a small console application.
